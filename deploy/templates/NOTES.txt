and applied the CONNECTION_* variables before the API pods rolled out.

them, `helm upgrade` re-runs the boot Job so the rows follow.
{{- else }}

through a Secret referenced by api.extraEnvFrom (see the chart's README).
{{- end }}

Back up the database together with the CREDENTIALS_ENCRYPTION_KEY in {{ .Values.secrets.secretName }}:
the connection credentials are encrypted with it, and a database restored
without it cannot read them.
