The API has no authentication: keep both hostnames behind your network
boundary (VPN, IP allow-list on the ingress, or an authenticating proxy).

The boot Job ({{ include "pixelaudit.fullname" . }}-boot) ran the migrations
and applied the CONNECTION_* variables before the API pods rolled out.
{{- if .Values.api.extraEnvFrom }}
Connections come from the Secret(s) under api.extraEnvFrom; after changing
them, `helm upgrade` re-runs the boot Job so the rows follow.
{{- else }}
No CONNECTION_* variables were given: add connections in the panel, or
through a Secret referenced by api.extraEnvFrom (see the chart's README).
{{- end }}

Back up the database together with SECRET_KEY: the connection credentials
are encrypted with it, and a database restored without it cannot read them.
{{- if .Values.postgresql.enabled }}

The in-chart PostgreSQL ({{ .Release.Name }}-postgresql) holds all the state;
it is meant for a try-out or a small install. For production, point
database.url at a Postgres you back up.
{{- end }}
